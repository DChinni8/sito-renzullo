# Sito Avv. Barbara Renzullo

Sito statico in HTML, CSS e JavaScript, senza passaggi di compilazione.
Per vederlo basta aprire `index.html` nel browser.

## Struttura

```
index.html        Home
profilo.html      Profilo e materie trattate
contatti.html     Recapiti, orari e modulo
privacy.html      Informativa privacy (bozza da completare)
assets/
  css/style.css   Stile e colori (in cima al file: palette)
  js/main.js      Menu mobile e modulo contatti
  img/foto/       Foto di Barbara e dello studio
  img/icone/      Favicon e loghi
```

## Da completare

- Foto di Barbara (spazio pronto nella pagina Profilo)
- Invio diretto del modulo (Formspree o Netlify Forms)
- Testo definitivo dell'informativa privacy
- Pubblicazione su GitHub Pages, poi dominio personalizzato
